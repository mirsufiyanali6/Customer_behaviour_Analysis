# Customer_behaviour_Analysis
This project analyzes customer shopping behavior to uncover valuable business insights using Python, SQL Server, Pandas, and Power BI. The dataset contains customer demographics, purchasing patterns, product preferences, payment methods, seasonal trends, discounts, and customer reviews

# Customer Shopping Behavior Analysis

## Overview

This project demonstrates an end-to-end data analytics workflow using Python, SQL Server, and Power BI. The objective is to analyze customer shopping behavior, uncover meaningful business insights, and present the findings through an interactive dashboard, a detailed report, and a presentation.

The project covers the complete analytics process—from loading and cleaning raw data to exploratory data analysis (EDA), SQL querying, visualization, and business reporting.

---

## Dataset

The dataset contains customer shopping transactions and includes information such as:

* Customer demographics
* Purchased products
* Purchase amount
* Payment method
* Discounts applied
* Review ratings
* Purchase frequency
* Shopping categories
